# 📚 Calculadora de Média do Aluno

Um programa simples desenvolvido em Python para calcular a média de duas notas de um aluno e informar se ele foi aprovado ou reprovado.

## 🛠️ Tecnologias utilizadas

- Python 3
- Visual Studio Code

# 📥 Como instalar e executar

### 1. Instalar o Python

Baixe e instale o Python pelo site oficial:

https://www.python.org/
